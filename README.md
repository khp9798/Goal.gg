# 풋살 매치 예약 및 통계 시각화 시스템

## 프로젝트 개요
이 시스템은 풋살을 즐기는 사용자들이 쉽고 편리하게 매치 일정을 알아보고 예약할 수 있도록 설계되었습니다. 사용자 스탯을 등록하고 이를 기반으로 다음과 같은 기능을 제공합니다:
- **오각형 그래프**를 통한 사용자 평균 스탯 시각화.
- **변화 추이 그래프**로 스탯의 시간별 변화 추적.
- K리그 선수 데이터를 기반으로 사용자의 스탯과 비슷한 선수 추천.
- 챗봇을 통한 추천 선수의 상세 정보 제공.

## 팀 소개
- **팀명**: 관통PJT 대전 3반 12기
- **팀원**: 김형표, 황성일

## 주요 기능
- **매치 예약 및 관리**: 사용자는 매치 일정을 검색하고 예약할 수 있습니다.
- **스탯 분석 및 시각화**: 매니저가 등록한 사용자 스탯을 시각적으로 분석하여 제공.
- **K리그 선수와의 비교**: 유사한 스탯을 가진 K리그 선수를 추천.
- **챗봇 연동**: 추천 선수에 대한 정보를 ChatGPT API를 통해 제공.

## 사용된 알고리즘

### 사용자 스탯과 K리그 선수 유사도 계산
프로젝트에서 K리그 선수와 사용자 스탯 간의 유사도를 계산하기 위해 **유클리디안 거리(Euclidean Distance)** 기반의 최근접 이웃 탐색 알고리즘을 사용했습니다.

1. **정규화 및 비율 계산**
   - 사용자 스탯 데이터를 정규화(Normalization)하여 비율을 계산합니다. 이를 통해 데이터의 스케일 차이를 제거하고 비교 가능한 형태로 만듭니다.

2. **거리 계산**
   - **Attribute Distance**: 사용자와 선수 스탯 간의 크기 차이를 측정하기 위해 유클리디안 거리 계산
   - **Shape Distance**: 스탯 분포의 유사도를 비교하기 위한 비율 기반 거리 계산

3. **최근접 이웃 탐색**
   - 두 거리 값(Attribute Distance, Shape Distance)을 기반으로 가장 유사한 선수를 탐색합니다.


### 프론트엔드
- **Framework**: Vue.js 3 (Vite)
- **주요 라이브러리**
  - `vue-cal`: 일정 관리 및 캘린더 UI 제공
  - `chart.js`: 데이터 시각화를 위한 차트 라이브러리
  - `bootstrap`: UI 구성 및 반응형 디자인 지원
  - `bootstrap-icons`: 프로젝트 내에서 아이콘 사용

### 백엔드
- **Framework**: Spring Boot
- **ORM**: MyBatis
- **서버**: 내장 Tomcat 서버
- **Build Tool**: Maven
- **라이브러리**
  - **Lombok**: 자바 코드에서 Getter/Setter, Constructor 등을 자동 생성하여 생산성 향상
- **API**
  - **카카오페이 API**: 결제 기능 제공
  - **카카오맵 API**: 지도 렌더링 및 위치 데이터 활용
  - **ChatGPT API**: 대화형 AI 응답 제공

## 데이터 수집
- **K리그 선수 데이터**: FIFA 인벤 사이트를 웹 크롤링하여 수집한 데이터입니다. 이를 통해 선수들의 스탯을 분석하고 유사도를 비교할 수 있도록 설계되었습니다.
